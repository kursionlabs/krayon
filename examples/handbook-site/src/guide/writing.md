# Write pages

Write a Markdown file with front matter for its title. The directory defaults
apply its layout and `parent` field, so the page appears in the shared sidebar.

| Source | Result |
| :--- | :--- |
| `guide/writing.md` | This page |
| `guide/publishing.md` | The next page |

Links to source files, such as [publishing](publishing.md), resolve to their
generated URLs. You can also return to the [guide overview](index.md).
