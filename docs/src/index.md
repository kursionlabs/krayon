# Krayon

Krayon builds static websites from Markdown, HTML, XML, JSON, and text
templates, site data, and assets. It is written in Kursal and produces files
for any static host.

Start with the [quickstart](start.md), then follow the [blog walkthrough](blog.md)
for a complete example.

## Guides and reference

- [Command-line tools](cli.md): initialize, build, check, and inspect routes.
- [Configuration](configuration.md): paths, collections, exclusions, and deployment URLs.
- [Content and Markdown](content.md): pages, defaults, aliases, drafts, and headings.
- [Templates](templates.md): layouts, includes, filters, and page queries.
- [Assets](assets.md): copying and content fingerprints.
- [Collections and generation](generation.md): generated pages, pagination, and navigation.
- [Output formats](formats.md): XML, JSON, and text templates.
- [Validation](validation.md): output safety and local link checks.
- [Development](development.md): repository layout and tests.
