# API reference

The API reference is generated from Krayon's current Kursal source. Build
the complete documentation site from the repository root with:

```sh
python3 scripts/build_docs.py
```

That command replaces this guide-side placeholder with the generated API
index at `/api/`. It includes Krayon's library packages, with searchable
module, type, function, and source pages.
